# Haul Desk

A CRM for a junk removal business that you can add to your phone's home screen: leads, quotes, schedule, customers, expenses and reports.

- Works offline. Everything is saved on the device, and nothing is stored in this repository.
- Use **Settings → Data → Save backup** regularly. **Restore backup** loads a backup onto a new phone.

Hosted with GitHub Pages. Open the site on your phone, then:
- **iPhone (Safari):** Share → Add to Home Screen
- **Android (Chrome):** ⋮ → Add to Home screen / Install app
